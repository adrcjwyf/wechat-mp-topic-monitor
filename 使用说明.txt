第一次使用
将 Windows x64 便携 ZIP 完整解压到可写文件夹，双击“启动自动监测.cmd”。首次启动会打开“抓文章与设置”。源码用户请按 README.md 安装 Python 3.10+ 和 requirements.txt。

抓文章与设置
填写自己取得的极致了 API Key，有附加码时一并填写。添加公众号的准确名称，启用要抓取的账号并保存。新账号可先试拉 1 页。补抓历史时选择日期范围、每号页数上限和最低保留余额，免费预览覆盖区间与预计费用，核对后再确认。日常更新可选择抓最新文章。试拉与实际抓取可能产生第三方费用。
接口地址默认使用极致了。如需修改，在本页底部展开配置，编辑 API 接口地址后保存。
极致了充值后可点「刷新余额」。补抓历史和更新最新也会先免费查余额。自定义接口充值后，可清空旧余额并放行首请求。更换 Key 或接口会重置余额、单价和总页数，历史文章仍可查看。

关键词
统一入选词、疑似词和排除词适用于所有公众号。例如将“政策评估”设为入选词，“征求意见”设为疑似词，“活动报名”设为排除词。如果某个词仅对单个公众号有用，可在该号下添加专属入选词或排除词。输入词语后按回车或点添加，点 × 移除。保存并重算即可用新词重新筛选本地文章，重算免费。

筛选结果与全部文章
“筛选结果”分栏显示入选和疑似文章，可以查看判定依据。“全部文章”可按条件检索已抓到的所有稿件，导出适合 Excel 阅读的 CSV。需要人工或 AI 复核时，可使用页面上的 Markdown 导出入口。文章和已保存的规则均在 data/wechat_mp.db。

分享或迁移
双击“导出分发包.cmd”。模式 1 分享空白程序。模式 2 分享历史与规则，清空专用凭据并关闭定时检查。模式 3 保留个人配置和凭据，仅供本人或有权使用这些凭据的人迁移。两种历史包都附同一份数据库快照生成的全量 CSV。
移动安装位置前请先双击“停止并取消自启.cmd”。将整个文件夹复制到新位置后重新启动。遇到启动问题可查看 data/monitor.log。
